### git commit
1. feat: [branch] add new <feature name>
   - add new feature
2. fix: [branch] fix <bug name>
   - fix bug
3. docs: [branch] add <documentation name>
   - add new documentation
4. style: [branch] add <style name>
   - add new style
5. refactor: [branch] simplify <logic>
   - simplify logic / module without change main functionality
6. perf: [branch] improve <performance name>
   - improve performance
7. test: [branch] add <test name>
   - add new test
8. chore: [branch] update <part name>
   - update part of project without effect to source code (like depent)
9.  ci: [branch] update <part name>:
    - update part of CI tools
10. build: [branch] update <part name>
    - update part of build tools
11. revert: [branch] undo <commit>
